# MowaLang

MowaLang is a dynamically typed, Telugu-based programming language built with Go. It lets you write expressive programs using Telugu syntax and shows iconic Telugu movie dialogues when your code succeeds or fails. It was designed to make programming fun, relatable, and culturally rooted — especially for Telugu speakers.

Run your code on Windows, Linux, or macOS, enhance your workflow with our VS Code extension, or experiment in our online playground. Visit [mowalang.pvarma.dev](https://mowalang.pvarma.dev) to dive into the MowaLang experience!

## Features

- **Telugu-Inspired Syntax**: Use keywords like `mowa`, `idhi`, and `okavela` for a culturally rich coding experience.
- **CLI Tool**: Execute `.mowa` files effortlessly with the `mowa -r` command.
- **VS Code Extension**: Enjoy syntax highlighting, autocompletions, and CodeLens for `.mowa` files (Run button coming soon).
- **Online Playground**: Test MowaLang code directly in your browser at [playground](https://mowalang.pvarma.dev/#playground).
- **Movie Dialogues**: Outputs include random Telugu Actor dialogues for a fun twist.

## Usage

### Running MowaLang Code

1. **Create a `.mowa` File**:
   Write your MowaLang code and save it with a `.mowa` extension (e.g., `hello.mowa`):
   ```bash
   mowa "Hello, MowaLang!"
   ```
2. Run via CLI: Open a terminal, navigate to your file’s directory, and run:
   ```bash
   mowa -r hello.mowa
   ```
3. See the Magic: Expect output like:
   ```bash
   Hello, MowaLang!
   Prabhas:'Jai Maahishmathi!'
