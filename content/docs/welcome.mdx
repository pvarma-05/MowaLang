## What is Mowa-Lang?
<span className="font-semibold">MowaLang</span> is a <span className="underline underline-offset-4">dynamically typed</span>, Telugu-based programming language built with **Go**.
It lets you write expressive programs using  Telugu syntax and shows **iconic Telugu movie dialogues** when your code succeeds or fails.

## Why was it Built?
MowaLang was created to make learning programming fun and relatable, especially for Telugu-speaking audiences.
It’s also a technical playground to explore interpreters, type systems, and language design.

## Telugu Syntax + Movie Dialogues = ❤️

You don’t just write code—you write as if you’re speaking Telugu.
And the output isn’t boring—it greets you with an **epic film dialogue** whenever your program succeeds or fails.

**sample.mowa:**
```ts
mowa "Hello Mowa!";
```
**output:**
```js
Hello Mowa!

Prabhas: 'Trust No-One, Kill Anyone, Be Only One'
```

## Who Should Use MowaLang?
<ul>
 <li>Beginners who want a fun introduction to programming</li>
 <li>Telugu speakers who enjoy seeing their language and culture reflected in tech</li>
 <li>Developers who are interested in language design, interpreters, and WebAssembly (WASM)</li>
</ul>
