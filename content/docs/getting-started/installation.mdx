## Follow these Steps

1. Go to <a href="/downloads">Downloads</a> and install script for your OS.
2. after downloading, go to that folder and run that script
<Callout type="warn" className="bg-yellow-400 font-semibold">
Make sure you run the script in administrator in Windows and sudo in Mac & Linux
</Callout>
3. Now Reopen your terminal and type ```mowa -h ``` and you will see the help menu.
