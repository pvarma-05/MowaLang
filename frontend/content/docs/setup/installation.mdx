> <span className="not-italic">"Before you start using <span className="text-[#A93E39] underline underline-offset-4">MowaLang</span>, you need to install it on your operating system. The CLI version supports more features than the web playground."</span>

## Follow these Steps

1. Go to the <a href="/downloads">Downloads</a> page and download the installation script for your OS.
2. After downloading, navigate to the downloaded folder and run the script.

<Callout type="warn" title="Important">
Make sure to run the script as Administrator on Windows, or with sudo on macOS and Linux.
</Callout>

3. Reopen your terminal and type <code>mowa -h</code>. You should see the help menu.

If everything was set up correctly, you'll see an output like this:
