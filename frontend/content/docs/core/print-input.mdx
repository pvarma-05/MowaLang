## Overview

In MowaLang, you can **display output** to the console using the `mowa` keyword and **accept user input** using the `theesko` keyword. These two operations are essential for interacting with your programs.

## Input-Ready Variables
To take input from the user, the variable must have a type. Otherwise, MowaLang can’t infer what kind of input it should expect.


### Correct ✅:

```bash
idhi username : string;
idhi age : number;
```
### Wrong ❌ (not allowed):

```bash
idhi something;
```
